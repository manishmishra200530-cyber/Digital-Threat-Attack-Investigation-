# Digital Threats Attack Investigation Tool

A Python-based automated cybersecurity script designed to analyze suspicious URLs, detect potential phishing vectors, calculate a threat score, and generate detailed incident investigation reports.

## 🚀 Features
- **URL Security Check:** Detects HTTP vs HTTPS connections.
- **IP Detection:** Flags raw IP addresses used in place of domain names (common phishing tactic).
- **Keyword Analysis:** Scans for high-risk words like `login`, `verify`, `paypal`, `secure`, etc.
- **Automated Reporting:** Appends findings and threat scores into `threat_investigation_report.txt`.

## 🛠️ Tech Stack
- Python 3 (Regular Expressions, URL Parsing, File Handling)
